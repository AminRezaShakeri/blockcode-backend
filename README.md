# بلوک‌کُد

کتابخانه‌ی فارسی فرمان‌های Minecraft. پروژه دو حالت دارد:

- **GitHub Pages:** حالت نمایشی قبلی، بدون حساب واقعی یا پرداخت.
- **Node.js:** حساب ایمیلی، کیف توکن سروری، تأیید ایمیل و اتصال اختیاری زرین‌پال.

## اجرای محلی در ویندوز

Node.js نسخه‌ی ۲۲ یا بالاتر را نصب کن. سپس در PowerShell:

```powershell
cd "$HOME\Desktop\MinecraftCodesSite"
Copy-Item .env.example .env
npm.cmd install
npm.cmd start
```

در مرورگر `http://localhost:3000` را باز کن. در حالت توسعه، پیوند تأیید ایمیل در ترمینالی که سرور را اجرا کرده چاپ می‌شود و پس از ثبت‌نام روی صفحه هم نمایش داده می‌شود. این حالت فقط برای توسعه‌ی محلی است.

## ایمیل در هاست

برای ارسال ایمیل واقعی، در تنظیمات محیطی هاست این مقادیر را تنظیم کن:

```text
NODE_ENV=production
APP_URL=https://دامنه-خودت
MAIL_MODE=smtp
SMTP_URL=smtps://نام‌کاربری:رمز@smtp.example.com:465
SMTP_FROM=BlokCode <no-reply@دامنه-خودت>
```

آدرس SMTP و رمز را فقط در تنظیمات محرمانه‌ی هاست وارد کن؛ آن‌ها را در GitHub یا داخل فایل‌های پروژه قرار نده. برای `APP_URL` باید همان نشانی HTTPS باشد که کاربران با آن سایت را باز می‌کنند.

## زرین‌پال

بسته‌ی سایت ۱۰٬۰۰۰ تومان است. سرور برای زرین‌پال مبلغ ثابت ۱۰۰٬۰۰۰ ریال می‌فرستد و فقط بعد از تأیید تراکنش از سمت زرین‌پال، ۱۰ توکن را به موجودی کاربر اضافه می‌کند.

پرداخت عمداً پیش‌فرض خاموش است. برای آزمایش درگاه، شناسه‌ی پذیرنده‌ی آزمایشی خودت را در تنظیمات محیطی سرور قرار بده:

```text
PAYMENTS_ENABLED=true
ZARINPAL_MERCHANT_ID=شناسه-پذیرنده
ZARINPAL_SANDBOX=true
```

تا وقتی آزمون کامل نشده و پذیرنده‌ی واقعی نداری، `ZARINPAL_SANDBOX=true` را نگه دار. برای پرداخت واقعی باید پذیرنده‌ی فعال داشته باشی، خودت پس از تصمیم‌گیری `ZARINPAL_SANDBOX=false` را تنظیم کنی و متغیر `PAYMENTS_ENABLED` را فقط در همان سرور روشن کنی. کلید پذیرنده را هرگز وارد صفحه یا فایل JavaScript نکن.

## استقرار

GitHub Pages فقط فایل‌های ایستا را اجرا می‌کند و نمی‌تواند `server.js` را اجرا کند. برای حساب واقعی و پرداخت، همین پروژه باید روی هاست Node.js اجرا شود و دامنه به همان سرویس اشاره کند. در تنظیمات سرویس این موارد را انجام بده:

1. دستور نصب: `npm install`
2. دستور اجرا: `npm start`
3. متغیرهای ایمیل و زرین‌پال بالا را در بخش محیطی سرویس تنظیم کن.
4. برای `DATA_DIR` یک فضای ذخیره‌سازی دائمی انتخاب کن؛ پایگاه‌داده‌ی SQLite داخل آن است.
5. از پوشه‌ی داده و پایگاه‌داده پشتیبان بگیر.

اگر فایل‌های صفحه را همچنان از GitHub Pages باز کنی، حساب و خرید واقعی فعال نمی‌شوند؛ صفحه باید از همان سرویس Node بارگذاری شود تا `/api` و فایل تنظیمات سرور در دسترس باشند.

## نکته‌ی امنیتی

رمزهای عبور با `scrypt` هش می‌شوند، نشست‌ها با کوکی `HttpOnly` نگهداری می‌شوند، و موجودی روزانه، بازشدن راز و پرداخت در تراکنش‌های پایگاه‌داده تغییر می‌کند. فعال‌کردن پرداخت واقعی به تنظیم امن دامنه‌ی HTTPS، ایمیل، پذیرنده و نسخه‌پشتیبان نیاز دارد.
